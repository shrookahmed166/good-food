# موقع مطعم 🍽️

موقع ويب متجاوب لمطعم. الهدف منه عرض المنيو، الحجز أونلاين، وتوفير معلومات عن المطعم.

## المميزات
- **تصميم متجاوب**: بيشتغل على الموبايل والتابلت والكمبيوتر
- **قسم المنيو**: المنيو متقسم لأقسام مع الصور والأسعار
- **تجربة مستخدم سلسة**: تصميم نضيف وحركات بسيطة

## الأدوات والتقنيات المستخدمة
- **اللغات**: HTML5, CSS3, JavaScript
- **التصميم**: Bootstrap 5
- **الأيقونات**: Font Awesome
